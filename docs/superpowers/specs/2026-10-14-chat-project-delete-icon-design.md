# Chat 项目删除图标设计

## 目标

在 Chat 左侧项目树的项目标题行提供可发现的删除入口，让用户能从截图中的项目行直接删除项目，而不必跳转到项目页。

## 交互

- 项目行悬停或键盘聚焦时，在现有重命名铅笔与新建聊天加号之间显示垃圾桶图标。
- 图标有明确的“删除项目”可访问名称，使用破坏性颜色和按钮样式。
- 点击图标不折叠项目、不创建聊天；它打开确认对话框。
- 确认对话框说明：项目会删除，聊天将保留并归入未分类；同步到本机的项目目录和其中文件会移入系统废纸篓。
- 用户取消则不发起请求；确认后调用现有项目删除 mutation。请求失败保留 UI 数据并显示错误提示。

## 数据与边界

- 复用现有 `useDeleteProject`，不新增删除 API 或客户端状态。
- 成功删除后的项目列表由现有 Query 缓存失效和服务端事件收敛。
- 本机目录删除仍由 `multica sync` 执行；浏览器 UI 不访问本机文件系统。

## 测试

- 项目行在可操作状态提供“删除项目”按钮。
- 点击按钮打开确认对话框，而不会触发项目折叠或新建聊天。
- 取消不调用 mutation；确认以对应项目 ID 调用 mutation。
