# Chat 输入快捷键

## 目标

在 Multica 的 Web 与桌面客户端中统一聊天输入行为：`Enter` 发送，`Shift + Enter` 换行。

## 行为

1. 非组合输入状态下，按 `Enter` 时阻止 textarea 的默认换行并调用既有发送回调。
2. 按 `Shift + Enter` 时不拦截事件，保留 textarea 默认换行。
3. 输入法组合输入期间（`isComposing`）不发送；`Enter` 继续用于确认候选词。
4. 空白内容、禁用状态或已有发送请求进行中时，不发送。
5. 共享聊天输入组件承载该规则，因此 Web 与桌面端保持一致。

## 测试

- `Enter` 调用发送回调且不插入换行。
- `Shift + Enter` 不调用发送回调。
- 组合输入期间的 `Enter` 不调用发送回调。
- 空白输入或禁用状态的 `Enter` 不调用发送回调。

## 范围

仅改变聊天输入的键盘交互与相关测试；不改变消息 API、发送按钮、快捷键设置或其他编辑器。
